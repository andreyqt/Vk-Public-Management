Rest-приложение для взаимодействия с VK API на основе сервисного ключа, ключа пользователя и ключа сообщества.
Проект разработан для личного/локального использования с целью администрирования сообщества, получения аналитики,
знакомства с [VK API](https://dev.vk.com/ru/reference) и совершенствования навыков программирования на Spring Boot.
